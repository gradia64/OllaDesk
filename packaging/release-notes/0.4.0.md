## What's new

- **Tools (🔧, off by default)**: with models that can call tools, the new 🔧 button in the input lets the model read the folders and files attached to the conversation by itself while it answers. It can list a folder, read a file in blocks of 400 lines (PDFs and documents included) and search for text in text and code files. The tools only read, and only what was attached, with the same exclusions as a folder used as context: hidden files, dependencies, `.gitignore`, credentials, and links that lead outside. The choice is saved per conversation, and the phone follows it.
- **Web search as a tool**: with 🔧 and 🌐 both on, the model searches the web when it needs to, writing its own query, instead of the automatic search before the answer. It can also open one of the pages it found to read its text, but only pages from its own searches and never addresses on the local network. With the search it also gets today's date. If the search fails twice in a row, the web tools are removed and the model answers without them. With 🌐 off, nothing goes online.
- **Tool calls in the chat**: the calls appear in the bubble in a collapsible "🔧 Tools used" block, with the arguments and the start of each result, and the tool in progress shows while the model answers. Search results go into "🌐 Sources" (the first 3 of each search, at most 10). The web companion shows the calls too, without controlling them. A model gets at most 8 rounds of tools per answer and knows how many are left. It also knows the shared files are read-only, so it does not claim to have changed them.
- **Data import in the Flatpak**: on first launch the Flatpak offers to import the data of OllaDesk installed as `.deb`, AUR or AppImage. You pick `~/.config/olladesk` in the file picker, and conversations, settings, model parameters and pasted images are copied, with no extra file system permission. Paired phones are not imported: the companion stays off until you pair them again. The summary shows the Ollama server and the search service of the imported settings. You can import again later from Settings → Info.

## Fixes

- **Smaller Flatpak**: the bundle no longer ships LLVM, clang and the PySide6 development tools from the PySide base app. The installed app goes from 320 to 119 MB, the bundle from 59 to 20 MB.
- **Ollama update in the Flatpak**: "Update now" cannot work inside the sandbox, so it is hidden there; when an update is available, Settings shows the command to run in a terminal.
- **Settings menu**: with the KDE style, the selected item in the Settings menu covered the ones next to it.
- **Flatpak log**: KDE's repeated udisks2 warnings no longer fill the terminal.

## Security

From an external review of this release, before the tag.

- **Page reading**: the address of a page is checked and then connected to as checked, so a domain cannot switch to a local address between the two steps (DNS rebinding). The time limit now covers the whole download, so a page sent one byte at a time is cut off, and compressed responses are refused.
- **Web search and shared files**: file content reaches the model as data, not as instructions, and a search query that repeats text read from the shared files is refused. A risk remains: a file or page with hidden instructions can push the model to put what it read, summarized or reworded, into a query, which goes to the search service. Keep 🌐 off when confidential files are shared.
- **Import**: a folder prepared by someone else could pair their phone with your companion and send your chats to their server without telling you. Phones are no longer imported, and the summary shows where chats and searches will go.
- **File tools**: a named pipe could block the tool forever, and a link inside a shared folder could reach hidden, ignored or credential files. Both are now excluded, very large folders are listed within a time limit, and the app's own data folder is never shared with the tools.
- **Robustness**: a hostile `.gitignore` could freeze the app for minutes; settings or model parameters of the wrong type could stop the app from starting or sending; a file name that is not valid UTF-8 could break saving. All three are handled now. Tool calls are capped at 8 per round with short arguments, and a call marker split between two chunks of the answer is still recognized.

## Technical notes

- **Flathub**: the release workflow generates and lints a Flathub manifest from the tag (`flathub` artifact). Submission to Flathub is postponed; the Flatpak stays available as a signed bundle in the GitHub release.
- **CI**: `flatpak-builder-lint` checks the manifest on every build, and a content check keeps the README translations aligned.
