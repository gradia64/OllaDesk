## New

- **Example questions can be hidden**: the four example questions on the start page can be turned off in Settings → General ("Examples").
- **Clearer notice at the tool round limit**: when the model uses up its tool rounds, the notice is now informational (ℹ instead of ⚠, since the model still answers with what it gathered) and says which tools the model used and how many times, for example "The model used the tools web search (5) and page reading (3) up to the limit of 8 rounds". Tool names are shown as translated labels; a tool without a label keeps its technical name.

## Fixes

- **Phone composer**: in the companion, after closing the virtual keyboard in a new conversation, the message box and the model choice disappeared, leaving only the header and an empty page. Now the page follows the space the keyboard leaves free: the composer stays above the keyboard while it is open and goes back to the bottom of the screen when it closes. Tested on Android with Chrome.
- **Narrower input bar on the PC**: with the sidebar closed, the message box spanned the whole window. It is now at most 760 px wide and centred, like the message column.
